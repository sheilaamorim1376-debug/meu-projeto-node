# Exemplo de Projeto Node.js: Variáveis e Funções
Este é um projeto básico em **Node.js** desenvolvido para demonstrar a estrutura inicial de uma aplicação, além de fornecer exemplos práticos de declaração de **variáveis** e criação de **funções** usando JavaScript moderno.

---

## 🛠️ O que foi feito?

1. **Estrutura de Pastas**: Organização limpa separando o ponto de entrada (`index.js`) do código fonte (`src/`).
2. **Exemplos de Variáveis (`src/variaveis.js`)**: Demonstração de uso de `const` (valores imutáveis) e `let` (valores mutáveis).
3. **Exemplos de Funções (`src/funcoes.js`)**: Demonstração de funções tradicionais e *Arrow Functions*.
4. **Exportação e Importação**: Uso do `module.exports` e `require` para conectar arquivos.
